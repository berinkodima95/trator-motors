# Trator Motors Україна — навчальний лендінг автосалону

Навчальний сайт автосалону вживаних і нових автомобілів у Києві, створений на основі безкоштовного шаблону **Trator — Car Rent Website Template** від [html.design](https://html.design/).

- Сайт: https://berinkodima95.github.io/trator-motors/
- Оригінальний шаблон без змін: https://github.com/berinkodima95/trator-original

Сторінки: головна, «Про нас», «Послуги», «Автомобілі» (каталог з фільтром), «Відгуки», «Контакти» (форма заявки на тест-драйв і карта).
Підключено Google Analytics 4 (воронка: перегляд каталогу → картка авто → заявка) і Microsoft Clarity (теплові карти).
